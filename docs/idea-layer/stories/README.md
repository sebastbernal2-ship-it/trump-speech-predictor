# Stories and events

A story/event is a real-world referent, distinct from the speech point about it and from any broader topic. Keep story identity and point identity separate; preserve source/timing evidence.

- [`story-graph-architecture.md`](story-graph-architecture.md) — graph entities, relations, and as-of constraints.
- [`2019-11-04-speech-news-circulation-case-study.md`](2019-11-04-speech-news-circulation-case-study.md) — one-speech circulation diagnostic.
- [`2019-full-year-preliminary-study.md`](2019-full-year-preliminary-study.md) — preliminary historical backtest.

Retrospective retrieval or publication timestamps do not prove contemporaneous availability; coverage/post counts do not prove audience virality.
