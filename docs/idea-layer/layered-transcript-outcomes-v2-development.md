# Layered transcript-outcome v2 development run

**Status:** development diagnostic only; not semantic gold, not a forecast evaluation, and not an untouched test set.

## Operational unit

This run uses the versioned idea definition in [`idea-atom-definition-v1.md`](idea-atom-definition-v1.md). Ideas are independently meaningful units of thought addressed in the transcript; transcript mentions preserve details and evidence; typed links distinguish direct expression from support, illustration, elaboration, qualification, and context. Schema v2 requires every idea to have at least one `expresses` link. The Python validator checks that structure, link resolution, and exact quote substrings, not whether a role/link is semantically right or whether the inventory is complete.

Extractor v2.3's quote handling accepts a normalization only when the model's exact normalized word-token sequence has one unique occurrence in the cited turn. It records the normalization and stores the actual transcript substring. A nonmatching extra citation is dropped only if that mention retains another exact citation; a mention with no exact citation fails validation. This narrowly addresses punctuation/case differences and does not fuzzy-match words. As a conservative format guard, the runner rejects an empty inventory for transcripts over 500 words rather than treating a likely failed extraction as `no_supported_idea`; the threshold is an engineering safeguard, not a semantic definition.

The reported totals are not accuracy, precision, recall, or semantic agreement. Structural validity and exact substring provenance do not establish that the quote supports the mention, that the link expresses the idea, that an idea is atomic, that the inventory is complete, or that forecastability is correct. No human review or independent reference labels were used. The 49 rows include outcomes generated by mutable model aliases from two providers; the complete target-speaker transcripts were sent to the configured providers. Provider/model names and response hashes are preserved per row, but aliases alone do not freeze weights.

## Long-transcript limitation and next gate

A smoke test on a 18,943-word 2019 transcript repeatedly failed single-pass extraction validation (including response-size/format, unsupported fields, and non-exact citations); one attempt returned an empty inventory after a failed repair, which is not accepted as evidence that the speech had no ideas. It remains outside the 49-event pilot artifact. The 2019 candidate corpus has 191 events; a uniform extraction over all of them is not complete. Before extending the protocol to long transcripts or building training/evaluation labels, design and test a chunked extraction/merge procedure that preserves cross-chunk idea identity and source provenance, then audit it with an independent reference or clearly bounded model-as-judge diagnostics. Keep the seven-day headline baseline and its chronological scores unchanged.
