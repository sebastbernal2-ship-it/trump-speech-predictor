# Transcript cleaning and candidate extraction v1

Run `python3 -m speechprefix.transcript_processing.candidates INPUT.jsonl NEW_OUTPUT_DIR --id-field speech_id --text-field text`. The output directory must be new and its parent must exist. The input is a selected top-level text field, not an automatically reconciled corpus or speaker selection. Each JSONL row retains the source path, line, field names, ID and raw/clean hashes; duplicate IDs remain distinct by line. A manifest records versions, lexicon hash, count and unreviewed outcome-only status. A failed run leaves an `INCOMPLETE` marker. Never overwrite or distribute local source data without checking its terms.

Cleaning removes leading/trailing whitespace and collapses each interior Unicode whitespace run to one space; all other characters, markup, disfluencies, speaker labels and annotations remain unchanged. `clean_to_raw` contains a half-open raw code-point span for each cleaned character, so evidence can be traced to the original text. Offsets in candidate evidence are half-open code-point offsets and the evidence is an exact cleaned-text passage; the raw span may contain different whitespace. The mechanical separator can operate on `clean_text` as a separate step; this does not retroactively change its original-text contract.

Topics are provisional single-word issue-anchor matches, and ideas are provisional multiword issue phrases from the existing `compact-issue-phrases-v2` extractor. Both include all matching punctuation-delimited passages and retain source identity in their enclosing row. This approximates the requested broader versus more specific distinction; phrase matches can be unrelated, misleading, duplicate or omit important content. Sentences, stage directions, headings and other speakers may yield false candidates in flattened input. Empty candidate lists mean no lexical match, not a reviewed absence of topics or ideas. No topic-to-idea relationship or stance is inferred. These are unreviewed outcome candidates, not exhaustive semantic labels, features for the same event, or evidence of training readiness.

Open choices include the source population and speaker attribution, duplicate versions, acceptable cleaning beyond whitespace, semantic topic/idea boundaries, linking ideas to multiple topics, stance and degree, and independent annotation and quality thresholds. Vocal tone requires separately aligned audio. Existing key-point research uses a different, more specific definition and is not silently reclassified here. Review source passages and evaluate coverage against independent references before treating candidates as targets.
